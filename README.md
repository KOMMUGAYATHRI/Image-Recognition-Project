# Image-Recognition-Project
A deep learning project for image classification using Python and TensorFlow.

## 📁 Repository Structure
- `FOOD_DATASET/`: Dataset containing images used for training and testing.
- `Image_Recognition_Model.ipynb`: Google Colab notebook containing model development and training code.

## 🛠️ Tools & Libraries Used
- **Language:** Python
- **Frameworks:** TensorFlow / Keras
- **Environment:** Google Colab

## 🚀 How to Run
1. Open `Image_Recognition_Model.ipynb` in Google Colab.
2. Ensure the dataset folder `FOOD_DATASET` is uploaded/linked in your environment.
3. Run all code cells sequentially to train and evaluate the model.
